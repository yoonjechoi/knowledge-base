# 지식베이스 schema

이 파일이 이 지식베이스의 schema 다. LLM 은 ingest · query · lint 를 하기 전에 이 파일을 읽고 따른다. 사람과 LLM 이 쓰면서 함께 고쳐 간다 — 「앞으로는 ~하자」가 나오면 여기에 적는다.

## 무엇을 쌓나

(setup 때 사람과 함께 적는다: 이 지식베이스의 주제 · 목적 · 주로 넣을 자료)

## 세 층

- `raw/` — 원자료. 글 · 논문 · 그림 · 데이터 파일. **고치지 않는다.** LLM 은 읽기만 한다. 사실의 원본이다. 그림은 `raw/assets/`.
- `wiki/` — LLM 이 쓰는 마크다운 페이지. 사람은 읽고, LLM 이 만들고 고치고 잇는다.
- 이 파일(`CLAUDE.md`) — 구조 · 약속 · 일하는 순서.

## 페이지 종류

| 폴더 | 페이지 | 한 페이지 = |
|---|---|---|
| `wiki/sources/` | 원자료 요약 | 원자료 하나 |
| `wiki/entities/` | 개체 — 사람 · 회사 · 제품 · 장소 · 작품 | 개체 하나 |
| `wiki/concepts/` | 개념 · 주제 · 방법 | 개념 하나 |
| `wiki/analyses/` | 비교 · 분석 · query 에서 나온 좋은 답 | 질문 하나 |
| `wiki/overview.md` | 전체 개요와 지금까지의 종합 | 한 장 |

주제에 맞게 폴더를 더하거나 바꿔도 된다. 바꾸면 이 표와 `wiki/index.md` 의 머리도 함께 고친다.

## 페이지 모양

```
---
type: source | entity | concept | analysis | overview
tags: [ ]
created: YYYY-MM-DD
updated: YYYY-MM-DD
sources: [raw/파일, …]      # 이 페이지 내용의 근거 원자료
---
# 제목
```

- 원자료 요약 페이지의 `sources` 에는 그 원자료 경로 하나(`raw/…`)를 적는다. 아직 ingest 하지 않은 원자료를 이것으로 찾는다.
- 사실에는 근거를 붙인다: `[[sources/요약-페이지]]` 또는 원자료 경로.
- 페이지끼리는 `[[폴더/파일-이름|보일 이름]]` 으로 잇는다. 실제로 이어지는 것만.
- 새 자료가 옛 주장과 어긋나면 지우지 않고 `> 어긋남:` 으로 둘 다 남긴다.
- 파일 이름은 띄어쓰기 대신 하이픈.

## index.md · log.md

- `wiki/index.md` — 내용 목록. 종류(폴더)마다 머리를 두고 `- [[페이지|이름]] — 한 줄 요약 · (선택) 날짜 · 원자료 수`. ingest 때마다 고친다. query 는 이것부터 읽는다.
- `wiki/log.md` — 시간순 기록. 맨 아래에 덧붙이기만 한다. 머리 모양: `## [YYYY-MM-DD] ingest | 제목` · `## [YYYY-MM-DD] query | 질문` · `## [YYYY-MM-DD] lint | 찾은 것`.

## 내 방식

(쓰면서 정해지는 것을 적는다. 예: ingest 때 무엇을 강조할지, 답은 어떤 모양을 좋아하는지, lint 는 얼마나 자주)

- 하나씩 넣을 때는 핵심을 사람과 이야기하고 쓴다. 여러 개를 한꺼번에 넣을 때는 덜 지켜보며 뒷단에서 쓴다.
- 지식베이스는 git 저장소다. 작업이 끝날 때마다 바꾼 파일만 커밋한다.
