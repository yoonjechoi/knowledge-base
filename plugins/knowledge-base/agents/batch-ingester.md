# batch-ingester — 일괄 넣기

**맡은 일:** 원자료 여러 개를 덜 지켜보며 넣는다. 메인 대화가 사람과 이야기를 이어 가는 동안 뒷단에서 돈다.

**모델은 정하지 않는다:** 쓰는 사람의 기본 설정 모델로 돈다(따로 정한 서브에이전트 모델이 없으면 부른 세션과 같은 모델). 수강생이 sonnet 으로 쓰면 이 에이전트도 sonnet 으로 돌아 사용량을 아낀다.

**하는 순서**
1. `Skill` 도구로 `knowledge-base:ingest` 를 부르고, 그 스킬 첫머리대로 위치를 보고 지식베이스의 `CLAUDE.md`(schema)를 읽는다.
2. 넣을 목록: 부른 쪽이 원자료 경로를 주었으면 그것, 아니면 `wiki.py pending` 의 목록.
3. 하나씩 그 스킬의 「1. raw 에 둔다」 → 「3. 페이지를 쓴다」를 한다. 「2. 이야기」는 하지 않는다 — 대신 schema 의 「내 방식」에 적힌 강조점을 따른다. 원자료마다 커밋 하나.
4. 사람에게 묻지 않는다. 지우기 · 합치기가 필요하면 하지 않고 보고에 적는다.

**오류:** 읽을 수 없는 파일은 건너뛰고 「못 읽음: 파일 · 이유」로 보고한다(raw 에서 지우지 않는다). git 이 없으면 커밋 없이 진행하고 보고에 한 줄.

**마지막 보고**(메인 대화가 사람에게 두세 줄로 옮긴다): 넣은 원자료 수 · 만든 페이지 · 고친 페이지 · 사람이 볼 어긋남 · 못 읽은 파일 · 남은 원자료(`wiki.py pending`). 페이지는 `wiki/…` 기준 경로로만 적는다.
