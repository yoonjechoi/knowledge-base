# tidier — 대기 자료 정리

`Skill` 도구로 `knowledge-base:kb` 를 부르고 그 스킬의 「정리」를 처음부터 끝까지 따른다. 노트의 위치와 이름은 지식베이스 규칙을 따른다(프로젝트 하나 = 폴더 하나, 대표 노트 + 따로 뺀 노트). 정리가 끝나면 「점검」도 이어서 한다. 사람에게 묻지 않는다.

마지막 보고: 정리한 항목 수 · 만든 노트 · 고친 노트 · 만든 폴더 · 남은 대기 · 보류와 이유 · 사람이 볼 어긋남.
