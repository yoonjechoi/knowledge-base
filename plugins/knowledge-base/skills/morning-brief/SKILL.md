# morning-brief — 아침 브리핑

예약 작업(권한 무시)으로 사람 없이 돌 수 있다. 묻지 않고 끝까지 간다.
이 스킬이 하는 것: 일지 읽기 · 「해 두면 좋은 일」을 일지에 넣기 · 브리핑 · ntfy 알림 한 건 · 화면 새로 고치기. **그 밖에는 아무것도 보내거나 지우거나 게시하지 않는다.**

## 순서

1. **해 두면 좋은 일 찾기** — 오늘 일지와 지난 7일 일지(있는 만큼 — 「며칠째」 같은 말은 일지로 확인될 때만)를 `python3 <이 스킬 폴더>/../kb/scripts/journal.py days` 로 꺼내 읽고 2~3개를 고른다: 며칠째 밀리는 할 일 · 마감이 다가오는데 손 안 댄 일 · 정했는데 안 한 일 · 답 안 한 연락 · 미리 준비할 것. 한 줄 = 「무엇 | 왜(짧게)」. 할 일로 넣을지는 사람이 정한다. 생일 같은 개인 일정은 넣지 않는다.
   오늘 일지의 `## 해 두면 좋은 일` 칸에 넣는다 — 저장은 **kb 스킬의 넣기(Ingest)**로(「지식베이스에 넣어 줘」 — 오늘 journal 노트의 그 칸만 바꾸고 다른 칸은 그대로).
   오늘 일지가 없으면 1번을 건너뛰고 2번에서 「일지가 아직 없어요」.
2. `python3 <이 스킬 폴더>/scripts/brief.py --send` — 오늘 일지로 브리핑 글을 만들어 보여 주고 ntfy 로 보낸다.
   모양(프로그램이 만든다 — 바꾸려면 `brief.py` 의 build 만 고친다):
   ```
   10.29 목 · 오늘 할 일 3개          ← 알림 제목
   오늘 할 일 / ☐ 할 일 · 무슨 일
   해 두면 좋은 일 / ＋ … · 왜
   이번 주에 마칠 것 / ☐ 할 일  D-3
   어제 한 일 / ☑ … (6개까지, 넘으면 「외 n개 — 일지에서」)
   빈 칸은 통째로 뺀다.
   ```
   알림: 중요도 high(낮으면 화면에 안 뜬다) · 꼬리표 sunrise · 누르면(Click) · 「일지 열기」 버튼 → journal-page 주소 `#d-오늘날짜`.
   **구독 이름 · 토큰은 내 설정(`~/.config/knowledge-base/config.json` 의 `ntfy_topic` · `ntfy_token`)에서 프로그램만 읽는다.** 아직 없으면 프로그램이 보내기만 건너뛰고 알려 준다 — 사람에게 「휴대폰 알림을 켜려면 『휴대폰 알림 설정해 줘』라고 하세요(ntfy-setup)」 한 줄. cat · 출력 · 일지 · 대화 어디에도 꺼내지 않는다.
   실패하면 brief.py 가 한 번 다시 보낸다. 또 실패하면 「알림 실패: 이유」 한 줄로 끝낸다(다른 통로로 보내지 않는다).
3. `journal-page` 스킬로 화면을 새로 올린다(1번에서 넣은 해 두면 좋은 일이 보이게). 에이전트로 불렸으면(Artifact 도구가 없으면) 건너뛰고 「화면 올리기는 메인에서」라고 보고에 적는다.
4. 끝에 brief.py 마지막 줄(「휴대폰으로 보냈어요」 · 실패 이유 · 건너뜀)을 그대로 전한다. 다시 보내기는 brief.py 가 한 번 한다 — 따로 다시 돌리지 않는다.
