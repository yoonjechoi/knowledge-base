# journal-page — 일지 화면

예약 작업(권한 무시)으로 사람 없이 돌 수 있다. 묻지 않고 끝까지 간다. 이 스킬은 **화면 만들기 · 아티팩트 올리기만** 한다.

## 순서

> `<이 스킬 폴더>` = 이 스킬을 불렀을 때 받은 Base directory. 옆 스킬은 `<이 스킬 폴더>/../<스킬 이름>/`.
1. `python3 <이 스킬 폴더>/scripts/render.py` → html 경로와 저장된 주소(`~/.config/knowledge-base/page-url.txt`)가 나온다.
   화면 모양은 `assets/template.html`(하루 = 한 화면: 큰 날짜 → 오늘 할 일 → 해 두면 좋은 일 → 이번 주에 마칠 것 → 어제 한 일 → 저녁 기록 → 다른 날, 빈 칸은 뺀다, 테두리 · 색 상자 없이 굵기와 크기로만). 모양을 바꾸라는 말이 있을 때만 틀을 고친다.
2. **아티팩트 올리기**
   - `page-url.txt` 에 주소가 **있으면** — 새 대화에서는 먼저 그 주소를 Artifact `read` 로 읽고(안 읽고 올리면 거절된다), 이어서 Artifact `publish` 에 `url` = 그 주소, `file_path` = 1번 html 로 덮어 올린다. 새 주소를 만들지 않는다.
   - **없으면** — 처음 한 번 새로 올리고(`icon: notebook`, 설명 한 줄), 받은 주소를 `~/.config/knowledge-base/page-url.txt` 에 적는다.
   - 공유 설정은 바꾸지 않는다. 새 아티팩트는 기본이 본인만이라 그대로 둔다.
   - Artifact 도구가 없는 환경이면 올리기를 건너뛰고 html 경로만 알린다. 다른 곳(문서 · 웹 호스팅)으로 대신 올리지 않는다 — 「나만」과 「같은 주소」를 지킬 수 없다.
3. 한 줄 보고: 화면 주소(+ `#d-오늘날짜`) 또는 「올리기 건너뜀 · html 경로」.

## 알아 둘 것

- 일지는 kb 스킬의 `scripts/journal.py` 가 꺼내 준다(render.py 가 부른다). 이 스킬은 일지 위치 · 칸을 모른다.
- 화면은 일지에 있는 것만 보여 준다. 「해 두면 좋은 일」은 morning-brief 가 아침에 일지에 넣은 것이다.
- `#d-YYYY-MM-DD` 가 없거나 없는 날이면 가장 최근 날을 연다.
