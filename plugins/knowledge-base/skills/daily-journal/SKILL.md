# daily-journal — 업무 일지 저장

예약 작업(권한 무시)으로 사람 없이 돌 수 있다. **묻지 않고 끝까지 간다.** 모르는 건 일지에 「확인 필요」로 적고 넘어간다.
이 스킬이 하는 것: 세션 읽기 · 일지 내용 만들기 · kb 넣기로 저장 · 화면 새로 고치기 · 정리 시각 옮기기. 저장은 kb 넣기에 맡긴다 — 걸리는 노트를 고치고 잇는 것까지 kb 가 한다. **그 밖에는 아무것도 보내거나 지우거나 게시하지 않는다**(메일 · 메시지 · 파일 지우기 없음).

설정: 모두에게 같은 값은 `<이 스킬 폴더>/config.json`(하루 경계 · 세션 폴더 · 뺄 폴더). 사람마다 다른 값(정리 시각 `last-run.txt` · 내 것만 뺄 폴더 `exclude_extra`)은 `~/.config/knowledge-base/`. 지식베이스 위치와 일지 모양은 kb 스킬만 안다.
> `<이 스킬 폴더>` = 이 스킬을 불렀을 때 받은 Base directory. 옆 스킬은 `<이 스킬 폴더>/../<스킬 이름>/`.


## 1. 모으기

`python3 <이 스킬 폴더>/scripts/collect_sessions.py collect`
- 범위 = 정리 시각(`last-run.txt`) ~ 지금. 파일이 없으면 어제 0시부터. 날짜를 받으면(`/daily-journal 2026-10-28`) `--since 2026-10-28T01:00 --until 2026-10-29T01:00` 으로 그 업무일만 다시 읽고, 4번의 정리 시각은 옮기지 않는다.
- 업무일(새벽 1시 경계, 이 컴퓨터 시간대)별로 나와 있다. 출력의 「끝 시각」을 기억한다.
- 「대화 0줄」이면 저장 없이 4번(정리 시각)만 하고 끝낸다.
- 그날 커밋도 본다: 출력에 나온 작업 폴더에서 `git log --since <범위 시작> --until <끝> --oneline`. 폴더가 git 저장소가 아니면 한 단계 아래 저장소들을 찾아 본다.
- 지식베이스의 그날 기록도 근거다: `wiki/log.md` 의 그날 줄 · 그날 생긴 `raw/notes/`.

## 2. 업무일마다 일지 내용 만들기

그날 일지가 이미 있으면 먼저 원문을 꺼내 본다: `python3 <이 스킬 폴더>/../kb/scripts/journal.py text <날짜>` — 이미 있는 일은 다시 넣지 않는다.
칸과 쓰는 법은 **kb 규칙의 journal 칸** 그대로(`<이 스킬 폴더>/../kb/references/rules.md`). 여기서 따로 정하지 않는다.
- 한 줄에 한 일, 근거 하나(커밋 해시 · 주소 · 파일 경로). 비밀번호 · 토큰 · 계좌 · 카드 번호 · ntfy 구독 이름은 넣지 않는다.
- 하루 먼저 끝난 할 일은 `[x]`. 「해 두면 좋은 일」은 morning-brief 가 쓰는 칸이라 여기서 쓰지 않는다.
- 지난 일지의 「내일 이어서」 줄 가운데 이번 범위에서 끝난 것은 그 줄을 `[x]` 로 바꾼다(지우지 않음 — 할 일과 같은 방식).

**다음 날 파일**에 미리 — 단, 그 업무일이 끝났을 때(다음 날 새벽 1시가 지났을 때)만. 아직 진행 중인 오늘 일지를 넣을 땐 다음 날 파일을 만들지 않는다(오늘 일지의 「내일 이어서」로 충분):
- `## 오늘 할 일` — 그날 못 한 할 일 + 「내일 이어서」 + 대화에서 "내일 ~" 한 것. 사람이 이미 적어 둔 할 일은 **덮어쓰지 말고 더하기만**.
- `## 이번 주에 마칠 것` — 그날 쪽에서 옮기고, 끝난 건 지운다.
- 사람과 대화하며 부른 경우(「오늘 한 일 넣어줘」)에는 내일 할 일을 같이 정한다. 그 밖(예약 작업 · 다른 스킬이 부름)은 AI가 정하고 그 칸 첫 줄에 「- AI가 먼저 정했어요 — 마음에 안 들면 고쳐 주세요」(이미 있으면 한 번만).

## 3. 저장 — kb 스킬로

날짜 파일마다 **`kb` 스킬의 넣기(Ingest)**로 저장한다 — 「지식베이스에 넣어 줘」처럼. 내용 파일이 원자료(`raw/`)로 들어가고, kb 가 규칙대로 그날 journal 노트를 쓰고 걸리는 고객 · 프로젝트 · 브랜드 노트도 고치고 링크한다. 지식베이스 규칙과 커밋은 kb 가 안다 — 여기서 git 을 직접 만지지 않는다.
내용은 임시 파일(`~/.cache/ai-secretary/journal-<날짜>.md`)로 만들어 넘긴다.

## 4. 화면 · 정리 시각

1. `journal-page` 스킬로 일지 화면을 새로 올린다(같은 주소).
2. 3번 저장이 다 성공했을 때만: `python3 <이 스킬 폴더>/scripts/collect_sessions.py commit --until <1번의 끝 시각>`
   중간에 실패하면 옮기지 않는다 → 다음번에 같은 범위를 다시 읽어 빠지는 시간이 없다.
