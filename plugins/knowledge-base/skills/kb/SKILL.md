# kb — 내 지식베이스

**지식베이스 위치:** 내 설정 `~/.config/knowledge-base/config.json` 의 `kb`(기본 `~/knowledge-base`, 처음 부를 때 없으면 기본값으로 만든다 — 옮기면 그 한 줄만). 확인: `python3 <이 스킬 폴더>/scripts/settings.py show` (원자료 `raw/` · 정리 노트 `wiki/` · 목록 `wiki/index.md` · 기록 `wiki/log.md`)

**어떤 작업이든 먼저 `<이 스킬 폴더>/references/rules.md` 를 읽고 따른다.** 칸 · 이름 · 링크 · 노트 모양 · 지키는 선이 다 거기 있다. 사람과 이야기할 때는 「위키」 대신 「지식베이스」.

| 말 | 작업 |
|---|---|
| 「지식베이스에 넣어 줘」 · 「이 파일 넣어 줘」 | Ingest |
| 「지식베이스에서 찾아 줘」 · 「예전에 ~ 어떻게 했지」 | Query |
| 「이 결론 지식베이스에 저장해 줘」 | Save (→ `wiki/synthesis/`) |
| 「지식베이스 점검해」 | Lint |

## Ingest — 넣기

1. 원자료를 `raw/` 에 둔다. 파일이면 복사(이름은 하이픈), 대화 내용 · 붙여 넣은 글이면 `raw/YYYY-MM-DD-제목.md` 로 저장(첫 줄에 어디서 온 것인지 · 날짜). 같은 이름이 이미 있으면 끝에 `-2` · `-3`. 이미 `raw/` 에 있으면 그대로. **raw 는 그 뒤로 고치지 않는다.**
2. 끝까지 읽고, 핵심 몇 줄을 사람에게 짧게 말한다. 답을 기다리지 않고 바로 이어 간다(무엇을 강조할지 사람이 말하면 그때 따른다). 사람이 없으면(에이전트 · 예약 작업) 그 몇 줄을 마지막 보고에 넣는다.
3. 걸리는 쪽을 찾는다 — `wiki/index.md` 를 먼저 읽고 `grep -ril` 로 이름 · 낱말을 찾는다. 있으면 **고치고**, 없으면 맞는 칸에 **새로 만든다**(규칙 2). 고치거나 만든 쪽 머리의 `sources` 에 이 원자료를 더한다. 원자료 하나가 여러 쪽(고객 · 프로젝트 · 브랜드 · 주제 …)을 건드리는 게 보통이다.
4. 원자료 요약 쪽이 필요하면 `topics/` 에(짧게, 근거 = raw 경로).
5. 이어지는 쪽끼리 `[[파일-이름|보일 이름]]` 링크. 어긋나는 옛 내용은 「어긋남」으로 남긴다.
6. `wiki/index.md` 고치기 → `wiki/log.md` 에 `## [오늘] ingest | 원자료 제목` + 건드린 쪽 → 바꾼 파일만 커밋.
7. 보고: 만든 쪽 · 고친 쪽 · 어긋난 곳.

## Query — 찾기

1. `wiki/index.md` 로 쪽을 고르고, 모자라면 `grep -ril` 로 더 찾는다. 그 쪽들을 읽는다. 위키에 없으면 `raw/` 까지 내려간다.
2. 근거 쪽(`[[링크]]` 또는 파일 경로)을 붙여 답한다. 지식베이스에 없으면 없다고 말한다.
3. 답이 다시 쓸 만한 비교 · 분석 · 결론이면 「지식베이스에 저장할까요?」 한 줄로 묻는다.
4. `log.md` 에 `## [오늘] query | 질문 한 줄` (커밋은 다른 작업과 함께).

## Save — 결론 저장 (「좋은 답은 다시 넣는다」)

1. 지금 대화에서 나온 결론 · 비교 · 분석을 `wiki/synthesis/제목.md` 새 파일로. 질문 · 결론 · 근거(근거 노트 `[[링크]]` · 원자료 경로) · 날짜. 정해지지 않은 건 「검토 중」.
2. 근거 쪽들에 `관련 결론: [[제목|…]]` 한 줄을 더한다.
3. 결론이 고객 · 프로젝트 · 브랜드의 지금 상태를 바꾸면 그 쪽도 고친다.
4. index · log(`## [오늘] save | 제목`) → 바꾼 파일만 커밋.

## Lint — 점검

1. `python3 <이 스킬 폴더>/scripts/lint.py` — 끊긴 링크 · 아무도 가리키지 않는 쪽 · index 에 빠진 쪽 · 띄어쓰기 든 파일 이름 · 위치가 규칙과 다른 파일을 찾는다.
2. 그다음 AI가 직접 본다: 쪽끼리 어긋나는 말, 새 자료가 이미 뒤집은 옛 주장, 자주 나오는데 쪽이 없는 이름 · 개념, 이어야 하는데 안 이어진 링크, 비어 있는 곳(검색으로 채울 만한 것)과 다음에 찾아볼 질문.
3. 표로 보고하고, **고칠지는 묻고** 고친다(쪽을 지우거나 합치는 건 꼭 먼저 묻는다).
4. `log.md` 에 `## [오늘] lint | 찾은 것 n개 · 고친 것 n개` → 커밋.

## 커밋

`cd <지식베이스 위치> && git add -- <바꾼 파일들> && git commit -m "<ingest|save|lint>: 한 줄"`. `git add -A` 는 쓰지 않는다(사람이 넣어 둔 raw 가 섞인다). 원격 저장소는 사람이 정한다.
