# kb — 옛 입구

지식베이스 동작은 카파시 LLM Wiki 처럼 ingest · query · lint 셋이고, 처음 한 번 setup 이다. 이 스킬은 `knowledge-base:kb` 로 부르던 곳(다른 플러그인 · 예약 · 지침)이 그대로 돌게 하는 입구일 뿐이다. 받은 말을 보고 `Skill` 도구로 아래 스킬을 부르고, 받은 인자를 그대로 넘긴 뒤 그 스킬을 따른다.

| 받은 말 | 부를 스킬 |
|---|---|
| 찾기 · 「예전에 ~ 어떻게 했지」 · 「○○ 보여 줘」 | `knowledge-base:query` |
| 결론 저장 · 결론 넣기 · 「이 결론 저장해 줘」 | `knowledge-base:query` 의 「좋은 답은 지식베이스에 남긴다」 — 받은 결론 · 근거 · 날짜 · 질문으로 `wiki/analyses/` 페이지를 쓴다(묻지 않는다) |
| 넣기 · 「이 파일 · 글 넣어 줘」 | `knowledge-base:ingest` |
| 「대기 자료 (일괄) 정리」 · 「바로 정리해 줘」 · 밀린 자료 | `knowledge-base:ingest` 의 일괄 넣기(`wiki.py pending` 의 목록) |
| 점검 | `knowledge-base:lint` |
| 지식베이스 만들기 · 설정 | `knowledge-base:setup` |

**다른 플러그인이 부를 때**
- 사람이 없으면 묻지 않고 끝까지 한다. ingest 의 「핵심 이야기」도 건너뛴다. 지우기 · 합치기는 하지 않고 보고에 적는다.
- 돌려줄 때 페이지는 `wiki/…` 기준 경로로만 말하고, 지식베이스 위치가 드러나는 경로는 돌려주지 않는다.
- 폴더 · 페이지 이름 희망이나 페이지 틀을 받으면 schema(`CLAUDE.md`)에 어긋나지 않는 한 따르고, 다르게 했으면 보고에 적는다.
- 지식베이스가 없으면 「지식베이스가 아직 없어요(setup 필요)」라고만 돌려준다.
