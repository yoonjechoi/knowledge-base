# setup — 지식베이스 처음 만들기

> `<스킬 폴더>` = 이 스킬을 불렀을 때 받은 Base directory. 도우미는 `python3 <스킬 폴더>/../../scripts/wiki.py`(윈도우에서 `python3` 이 없으면 `python`, 그것도 없으면 `py -3`).
> 사람에게는 「위키」 대신 「지식베이스」라고 한다.

카파시 gist 는 일부러 추상적이다 — 「이 글을 LLM 에이전트와 나누고 함께 내 판을 만들라」. setup 은 그 일을 한다: 뼈대를 만들고, 무엇을 쌓을지 사람과 정해 schema 에 적는다. schema 가 LLM 을 「아무 챗봇」이 아니라 「꼼꼼한 지식베이스 관리자」로 만드는 핵심 설정이기 때문이다.

1. `wiki.py where` 로 위치를 본다(기본 `~/knowledge-base`, 윈도우는 `C:\Users\내이름\knowledge-base`). 「지식베이스를 ○○ 에 만들까요? 다른 곳을 원하면 말해 주세요」 한 줄로 묻는다. 그 폴더에 이미 `CLAUDE.md` 와 `wiki/index.md` 가 있으면 새로 만들지 않고 그대로 쓴다고 알리고 4번으로 간다. `where` 가 「옛 구조」라고 하면(knowledge-base 0.x 의 `rules.md` · 대기 목록) 그대로 알리고 「옛 지식베이스를 `<폴더>-old-오늘` 로 옮겨 두고 새로 시작할까요?」라고 묻는다. 예면 `wiki.py move-old` 로 옮기고 이어서 2번. 옛 자료는 거기 남고, 필요하면 나중에 그 raw 를 ingest 한다. 다른 파일이 들어 있으면 알리고 다른 폴더를 권한다.
2. `wiki.py setup` (다른 곳이면 `wiki.py setup <폴더>` — 설정도 그 폴더로). `raw/` · `raw/assets/` · `wiki/`(sources · entities · concepts · analyses · `index.md` · `log.md` · `overview.md`) · schema `CLAUDE.md` 를 만들고, git 이 있으면 기록 저장소로 시작한다. 이미 있는 파일은 건드리지 않는다.
3. 지식베이스 폴더의 `CLAUDE.md` 가 schema 다. 그 폴더에서 Claude 를 열면 저절로 읽힌다.
4. **schema 를 함께 쓴다.** 한 번에 하나씩 짧게 묻는다.
   1. 무엇을 쌓을 지식베이스인가요? (주제 · 목적 — 예: 한 분야 공부, 책 읽기, 일 · 고객, 건강, 여행 계획)
   2. 주로 어떤 자료를 넣나요? (글 · 논문 · PDF · 회의 기록 · 사진 · 데이터)
   3. 페이지 종류가 기본(원자료 요약 · 개체 · 개념 · 분석 · 전체 개요)으로 맞나요? 주제에 맞는 종류가 따로 있나요? (예: 책이면 등장인물 · 주제 · 줄거리, 일이면 고객 · 프로젝트)
   4. 넣을 때 핵심을 같이 이야기하며 넣을까요, 알아서 넣을까요?
   답을 `CLAUDE.md` 의 「무엇을 쌓나」 · 「페이지 종류」 · 「내 방식」에 적는다. 종류를 더하면 `wiki/` 폴더와 `wiki/index.md` 머리도 만든다. 사람이 「알아서 해」라고 하면 기본대로 두고 「쓰면서 고쳐 가요」라고 한다.
5. `wiki/log.md` 에 `## [오늘] setup | schema 정함 — 한 줄` 을 덧붙이고 바꾼 파일만 커밋한다(`git -C <지식베이스> add <파일들>` → `commit -m "setup: …"`. git 이 없으면 건너뛴다).
6. 만든 구조를 ├── └── 그림으로 보여 주고, 쓰는 법을 세 줄로: 「『이거 지식베이스에 넣어 줘』 — ingest」, 「『지식베이스에서 찾아 줘』 — query」, 「『지식베이스 점검해 줘』 — lint」.
7. 원하면 도구를 안내한다(카파시의 팁):
   - **옵시디언** — 「폴더를 보관함으로 열기」로 지식베이스 폴더. 그래프 보기로 무엇이 이어졌는지 · 외톨이 페이지를 본다.
   - **Obsidian Web Clipper** — 웹 글을 마크다운으로 `raw/` 에 바로 넣는 브라우저 확장.
   - **그림 내려받기** — 옵시디언 설정 › 파일과 링크 › 첨부 파일 폴더를 `raw/assets/` 로, 단축키 「Download attachments for current file」.
   - **Dataview**(페이지 머리로 표 만들기) · **Marp**(지식베이스 내용으로 슬라이드).

## schema 를 나중에 고칠 때

「앞으로는 ~하자」, 「페이지 종류 더하자」, 「schema 다시 정하자」면 `CLAUDE.md` 를 고치고(폴더 · index 머리도 맞춤) log 에 `## [오늘] setup | schema: 바뀐 것` → 커밋. 위치를 옮기자면 `wiki.py setup <새 폴더>` 는 설정만 바꾸고 파일은 옮기지 않으니, 옮기는 것은 사람과 함께 확인하며 한다.
